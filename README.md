# Learning about Version Control
## Author: Lareina Lyu
Solving merge conflicts takes conscious effort, but I can do it!

- What I like most: Version control makes conflict more manageable. When changes are tracked, you avoid the surprise collisions that happen when everyone is editing the same files, and you can always see what changed and roll back if something goes wrong.

- What I find most challenging: Resolving merge conflicts and test thoroughly can still be time-consuming, especially in large codebases.
